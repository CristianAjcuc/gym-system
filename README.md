# Gym System

Sistema de gestión de gimnasio desarrollado en PHP, orientado al control administrativo y mejorado con un enfoque en seguridad informática.

##  Funcionalidades

- Gestión de socios
- Control de asistencia
- Administración de planes
- Suscripciones
- Control de caja
- Registro de gastos
- Gestión de usuarios

## Tecnologías

- PHP
- MySQL
- Laragon
- HTML / CSS / JS

##  Mejoras de Seguridad (Propuesta)

- Validación de entradas
- Control de accesos por roles
- Protección contra inyección SQL
- Arquitectura híbrida (On-Premise + Cloud)
- Implementación de buenas prácticas

##  Arquitectura

El sistema evoluciona desde un modelo básico (As-Is) hacia una arquitectura más robusta (To-Be), incorporando:

- Firewall
- WAF
- VPN
- SIEM
- IAM
- Monitoreo de logs
- Backups y recuperación

##  Objetivo

Fortalecer la seguridad del sistema, reducir vulnerabilidades y garantizar la integridad de la información.
